# Security

This repository is a portfolio demonstration and must contain only fictional data.

## Reporting

Please report security concerns privately to `ernestogomez.ing@gmail.com`. Do not include credentials, personal documents, or sensitive information in a public issue.

## Public Repository Rules

- Never commit `.env` files or database credentials.
- Never publish uploaded CVs, profile photos, or institutional documents.
- Use only fictional records in database exports.
- Replace the included demo password before any real deployment.
- Disable `APP_DEBUG` in production.
